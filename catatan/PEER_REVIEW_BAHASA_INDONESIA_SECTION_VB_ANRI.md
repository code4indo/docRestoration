## 📋 PRINSIP REVISI YANG DITERAPKAN

### ✅ **DIGANTI ke Indonesia:**
1. **Istilah umum** yang memiliki padanan baku:
   - training → pelatihan
   - input → masukan
   - output → keluaran
   - range → rentang
   - mean → rerata
   
2. **Deskriptor kualitatif:**
   - severe → parah
   - moderate → sedang
   - mild → ringan
   - successful → sukses
   - challenging → menantang
   
3. **Proses & metodologi:**
   - enhancement → peningkatan
   - cleaning → pembersihan
   - preservation → preservasi
   - evaluation → evaluasi
   - assessment → asesmen

4. **Hasil & metrik:**
   - improvement → perbaikan
   - reduction → reduksi
   - effectiveness → efektivitas
   - performance → performa

### ⚠️ **RETAINED (Bahasa Inggris) karena:**

1. **Istilah teknis ML/CV tanpa padanan baku:**
   - checkpoint (titik simpan kurang lazim)
   - epoch (era/periode tidak tepat)
   - SNR (Signal-to-Noise Ratio - akronim)
   - precision/recall (metrik ML spesifik)
   - trade-off (sudah diserap umum)
   - superior (komparatif teknis)
   - hallucination (fenomena ML spesifik)
   
2. **Nama proper/spesifik:**
   - Likert scale (nama skala psikometri)
   - Cohen's kappa (nama statistik)
   - foxing (istilah konservasi dokumen internasional)
   - bleed-through (fenomena spesifik dokumen)
   - iron gall ink (jenis tinta historis spesifik)
   
3. **Akronim/singkatan teknis:**
   - DPI (Dots Per Inch)
   - TIFF (Tagged Image File Format)
   - VOC (Vereenigde Oostindische Compagnie)
   - ANRI (Arsip Nasional RI)
   - SNR (Signal-to-Noise Ratio)

4. **Hybrid terms (kombinasi):**
   - "Artifak tinta iron gall" (iron gall ink artifacts)
   - "Penghilangan bleed-through" (bleed-through removal)
   - "Skala Likert 4-poin" (4-point Likert scale)
